# Sarvam V

**Sarvam V** is a full-suite, on-device video editor for Android — built as a tiny (~38 KB) APK that wraps a canvas-based editing engine.

## Features
- Multi-clip timeline: import, reorder, delete, trim in/out points
- 10 filter presets + brightness / contrast / saturation / hue / blur sliders
- Text overlays with drag-to-position, color, size and per-clip timing
- Background music with volume, offset and loop
- Crossfade transitions and per-clip fade in/out
- Per-clip speed (0.25x-4x) and volume
- Export: 480p-1080p, 24-60 fps, quality presets, WebM output saved to Downloads

## Install
Download `SarvamV.apk` from the [GitHub Pages site](https://samratbarman1013-commits.github.io/sarvam-v-app/) and open it on your Android 7.0+ phone. Allow installs from your browser when prompted.

## Privacy
All editing happens on your device. No analytics, no network access, nothing leaves your phone.
